## 🧠 Overview

Saber is a free After Effects plug-in from Video Copilot that renders procedural energy effects — lightsabers, lightning, electric arcs and neon strokes — from a mask path.

On a Windows machine it runs as a plug-in suite that loads inside Adobe After Effects CC 2015 or newer. Typical use is procedural energy effects for after effects work on local files, so the application does not need a subscription or a cloud project to open and save documents.

## 🚀 Key Features

| Feature | Description |
| --- | --- |
| ⚡ Energy Styles | Presets for lightsaber blades, lightning, electricity, neon and fire along a mask. |
| 🖊️ Mask-driven Shape | The effect follows any mask path, so the glow inherits the drawn curve. |
| 🎚️ Core and Glow Layers | Separate core width, glow intensity, spread and flicker controls. |
| 🌪️ Turbulence | Noise-driven displacement makes the beam crackle instead of staying perfectly smooth. |
| 🎨 Colour Gradients | Two-colour gradients with blend modes for the core and outer glow. |
| 🏎️ Motion Controls | Start and end offsets animate the beam growing or retracting along the path. |
